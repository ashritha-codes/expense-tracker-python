
# Expense Tracker

A simple Python-based Expense Tracker that allows users to add, search, and calculate their expenses.

## Features

- Add expenses
- Store expense name, amount, category, and date
- Search expenses by name
- Calculate total expenses
- Simple menu-based interface

## Technologies Used

- Python

## How It Works

The program provides a menu with four options:

1. Add Expenses
2. Search Expenses
3. Total Expenses
4. Exit

Expenses are stored using a Python list.
